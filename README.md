# Отчет по лабораторной работе №1

## Выполненные шаги
1. Загрузка датасета diabetes через sklearn и изучение первой части данных (`df.head()`).
2. Проверка типов данных и уникальных значений целевой переменной (`sex`).
3. Сохранение сырых данных в `data/raw/diabetes.csv`.
4. Введение пропущенных значений (10%) в столбцы `age` и `bmi` с помощью случайного выбора.
5. Определение числовых и категориальных признаков.
6. Создание кастомного трансформера `SquareFeaturesTransformer`, добавляющего квадраты числовых признаков.
7. Построение препроцессинга с помощью `ColumnTransformer`: 
   - Для чисел: добавление квадратов, импутация медианой, стандартизация.
   - Для категорий: импутация модой, One-Hot Encoding.
8. Создание пайплайна с `RandomForestRegressor` и настройка параметров через `GridSearchCV` (5-fold cross-validation).
9. Обучение лучшей модели и оценка на тестовой выборке.
10. Сохранение обученной модели в `models/best_diabetes_model.pkl` с помощью `joblib`.

## Полученные метрики
- Лучшие параметры поиска (GridSearchCV): `{'model__max_depth': 5, 'model__min_samples_split': 5, 'model__n_estimators': 50}`
- RMSE на тестовой выборке: **53.9824**
- R² (коэффициент детерминации): **0.4500**

## Выводы
- Модель RandomForestRegressor с предложенными гиперпараметрами показала умеренную предсказательную силу (R² ≈ 0.45), что типично для задач регрессии на реальных данных с шумом.
- Добавление квадратов признаков (`SquareFeaturesTransformer`) и корректная обработка пропущенных значений и категорий способствовали стабильности обучения.
- GridSearchCV эффективно нашел компактный набор параметров, избегающего переобучения (max_depth=5, минимальное количество выборок для сплита 5).
- Модель успешно сохранена для последующего использования. R² около 0.45 указывает на то, что около 45% дисперсии целевой переменной объясняется моделью, что является хорошим baseline для дальнейшей доработки (например, дополнительный feature engineering, другие модели или более детальная настройка параметров).
